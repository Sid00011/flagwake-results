# Flagwake signed runs

These are signed runs of [Flagwake](https://github.com/Sid00011/Flagwake), with a few hosted
models as the defender. Each run used Flagwake's own model agent and Flagwake's signing workflow
at a release tag, which the run's signature names.

- [PLAN.md](PLAN.md) holds the models, settings and rules. It was fixed before the first run.
- [RESULTS.md](RESULTS.md) has every run and every attempt, with how to check each one yourself.
- `results/` holds the signed reports, their signatures and attempt tickets, unchanged.

Every run drew its own fresh incidents, so the runs are not a ranking. The incidents are fictional
and the intruder is scripted, so a run shows behaviour in this test only.
